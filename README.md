### 🛠 Проекты

#### [envspy](https://github.com/roma36637-alt/envspy)
**Запускает вашу команду и показывает, какие переменные окружения она реально прочитала.**
Не грепает исходники: ловит имена, собранные в рантайме (`prefix + "_KEY"`), и переменные,
которые тянут библиотеки. Видит `os.environ["X"]` / `os.getenv("X")` / `os.getenv("X","d")`
как разные состояния. Значения никогда не записываются в лог.
Есть режим для CI: `envspy --check .env.example -- pytest` падает, если код читает то,
чего нет в `.env.example`.
<sub>Python + Node · stdlib · 6 тестов</sub>

#### [spillcheck](https://github.com/roma36637-alt/spillcheck)
**Чек о том, что изменила команда — включая файлы, которые Git игнорирует.**
Генератор или сборка должна писать только в разрешённую папку: выход за `--allow`
даёт код возврата `3`, удобно валить CI. Ловит то, что `git status` не покажет из-за `.gitignore`.
<sub>stdlib · Python 3.10+ · 4 теста</sub>

#### [repo-rpg](https://github.com/roma36637-alt/repo-rpg)
**Превращает профиль GitHub в RPG-карточку (SVG).**
Без зависимостей, CLI + GitHub Action для автообновления карточки, есть офлайн-режим `--from-json`.
<sub>stdlib · 16 тестов</sub>

#### [smeta-delta](https://github.com/roma36637-alt/smeta-delta)
**Объясняет, почему изменилась сумма сметы:** эффекты объёма, цены за единицу и состава работ.
Автономный HTML-отчёт, который можно открыть без интернета и без зависимостей.
<sub>stdlib · 18 тестов</sub>
